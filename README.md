# Energytool AI Consultant

Начальный прототип консультанта: веб-чат, поиск по локально переданной базе знаний, вызов совместимого API модели и локальное сохранение демонстрационных заявок. Исходные материалы организаторов и секреты в репозиторий не включаются.

## Запуск

Скопируйте `.env.example` в `.env`, задайте `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` разрешённого организаторами API. Создайте каталог `data` и положите в него предоставленный архив `knowledge-base.zip`. Запустите `docker compose up --build` и откройте http://localhost:8000. Без настроенного API или БЗ возвращается безопасный ответ о недостатке данных. Контакты используйте только вымышленные; заявки хранятся локально и не отправляются.

Локально: `python -m pip install -r requirements.txt`, затем `uvicorn app.main:app --reload`. Тесты: `python -m pytest -q`.

## Сабмит

Пример организаторов задаёт `DATA_DIR/questions.csv` (`id,question`) и `DATA_DIR/knowledge-base.zip`, результат — `submission.csv` (`id,answer`). Запуск: `python solution.py`. Команда `python package_submission.py` создаёт ZIP из кода и зависимостей; база знаний, вопросы и ключи в архив не входят. Реальный контракт и ограничения платформы следует подтвердить у организаторов.

## Статус и ограничения

Это **не законченная и не промышленная система**. Поиск лексический, без эмбеддингов и реранжирования; нет независимой проверки каждого утверждения, политики разрешения конфликтов, утверждения версий БЗ, административного интерфейса, RBAC, PostgreSQL, ограничения частоты запросов и полноценной защиты от инъекций. Модель может ошибаться даже при наличии контекста. Сессии и заявки хранятся в SQLite; локальный токен сессии предоставляет доступ к истории. Не используйте сервис с настоящими персональными данными и не публикуйте его в Интернет. Целевые показатели ТЗ не измерены. Перед передачей БЗ внешнему API необходимо подтвердить разрешение владельца данных.

Конкурсный адаптер обрабатывает строки независимо. Передача истории в регламентном формате, если она требуется помимо CSV-примера, нуждается в уточнении. Необходимо выполнить оценку на размеченном наборе, adversarial и нагрузочные испытания, проверить лицензию и требования к архиву, подготовить презентацию и согласовать доступ жюри.
