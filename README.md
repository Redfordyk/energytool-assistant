# Energytool AI Consultant

Начальный прототип консультанта: веб-чат, поиск по локально переданной базе знаний, вызов совместимого API модели и локальное сохранение демонстрационных заявок. Исходные материалы организаторов и секреты в репозиторий не включаются.

## Запуск

Скопируйте `.env.example` в `.env`. Задайте длинные случайные разные значения `POSTGRES_PASSWORD`, `ADMIN_TOKEN`, `REVIEWER_TOKEN`, а также `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` разрешённого организаторами API. Для пароля PostgreSQL в Compose используйте буквы и цифры: специальные символы в URL соединения требуют отдельного кодирования. Создайте каталог `data` и положите в него предоставленный архив `knowledge-base.zip`. Запустите `docker compose up --build` и откройте http://localhost:8000. Сначала зарегистрируйте, утвердите и активируйте БЗ по инструкции ниже. Без настроенного API или активной БЗ возвращается безопасный ответ. Используйте только вымышленные контакты: заявки сохраняются в PostgreSQL и не отправляются.

Локально: `python -m pip install -r requirements.txt`, `alembic upgrade head`, затем `uvicorn app.main:app --reload`. Без `DATABASE_URL` используется SQLite `energytool.db`; переход на PostgreSQL не переносит существующие SQLite-данные автоматически. Тесты: `python -m pytest -q`. Для интеграционного теста PostgreSQL задайте `TEST_DATABASE_URL` и предварительно примените миграции к отдельной тестовой БД.

## Управление базой знаний

Откройте http://localhost:8000/admin и введите токен администратора для регистрации, утверждения, активации и отзыва версий. Токен остаётся только в поле страницы. Регистрация и активация не заменяют ручную проверку документов: перед утверждением необходимо проверить полноту и правомерность использования. Файлы хранятся по хешу в `KNOWLEDGE_DIR`; перед использованием проверяется целостность. Кэш эмбеддингов привязан к содержимому.

Те же действия доступны через API с заголовком `Authorization: Bearer <ADMIN_TOKEN>`: `POST /api/admin/knowledge/register` регистрирует копию `data/knowledge-base.zip` и возвращает её SHA-256; `POST /api/admin/knowledge/{sha256}/approve`, `/activate` и `/revoke` управляют версией.

`GET /api/admin/knowledge` доступен также токену reviewer; `GET /api/admin/sessions/{session_id}/messages` позволяет reviewer и admin просмотреть историю конкретной сессии. Действия с версиями и просмотр истории записываются в аудит без текста сообщений. Это ограниченный ролевой доступ по общим токенам окружения, без персональных учётных записей, ротации или раздельного утверждения. Храните токены вне исходников и не предоставляйте их посетителям.

## Сабмит

Пример организаторов задаёт `DATA_DIR/questions.csv` (`id,question`) и `DATA_DIR/knowledge-base.zip`, результат — `submission.csv` (`id,answer`). Запуск: `python solution.py`. Команда `python package_submission.py` создаёт ZIP из кода и зависимостей; база знаний, вопросы и ключи в архив не входят. Реальный контракт и ограничения платформы следует подтвердить у организаторов.

## Статус и ограничения

Это **не законченная и не промышленная система**. Поиск объединяет BM25 и эмбеддинги через reciprocal rank fusion и при доступности использует реранкер. При отказе эмбеддера или реранкера поиск продолжается по доступным каналам. Ответ проходит проверку структуры, точности цитат и чисел, а затем отдельный вызов модели проверяет соответствие каждого утверждения цитате; ошибка проверки приводит к отказу. `VERIFIER_MODEL` позволяет выбрать отдельную модель; по умолчанию используется генератор отдельным вызовом, поэтому проверка не является независимой. Модель-проверяющий тоже может ошибаться; детерминированной проверки единиц и условий пока нет. Нет политики разрешения конфликтов, персональной аутентификации, ограничения частоты запросов и полноценной защиты от инъекций. Токен посетителя предоставляет доступ к своей истории. Не используйте сервис с настоящими персональными данными и не публикуйте его в Интернет. Целевые показатели ТЗ не измерены. Перед передачей БЗ внешнему API необходимо подтвердить разрешение владельца данных.

Конкурсный адаптер обрабатывает строки независимо. Передача истории в регламентном формате, если она требуется помимо CSV-примера, нуждается в уточнении. Необходимо выполнить оценку на размеченном наборе, adversarial и нагрузочные испытания, проверить лицензию и требования к архиву, подготовить презентацию и согласовать доступ жюри.
